# 🎓 College Event Website

A community website to display college events, schedules and registration details.

## Features
- View upcoming college events
- Event date and venue details
- Register button for each event
- Clean responsive design

## Technologies Used
- HTML5
- CSS3

## Purpose
Built for students to stay updated on all college events and activities.

## How to Use
1. Download or clone the repo
2. Open index.html in any browser
3. View all upcoming events!
